# Security policy

DeviceView is a static catalog UI: product data ships in the repository, and user data (favorites, site brief, share dismiss state) stays in the browser.

## Supported versions

Security fixes are applied on the default branch (`main`). Deploy your own instance from current `main` or tagged releases if you add them later.

## Reporting a vulnerability

**Please do not open a public issue** for exploitable security problems.

1. Use [GitHub private vulnerability reporting](https://github.com/dadishimwe/product-view/security/advisories/new) for this repository if enabled, **or**
2. Open a minimal private contact path with the maintainer (e.g. GitHub profile contact) describing impact and reproduction steps.

We will acknowledge reports within a reasonable time and coordinate a fix before public disclosure when appropriate.

## Out of scope

- Incorrect vendor specs (use the **Wrong or missing spec** issue template instead)
- Social engineering or issues in third-party vendor sites linked from the catalog
